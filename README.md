# Note Creator

## Описание

Note Creator — это серверное API-приложение для создания и управления заметками. Проект построен на фреймворке NestJS, использует PostgreSQL и TypeORM для работы с базой данных. Реализована ролевая модель доступа (RBAC) для безопасного управления пользователями и заметками.

Основные возможности:
- аутентификация и авторизация с разделением ролей;
- создание, чтение, обновление и удаление заметок;
- поиск пользователей по UUID;
- модульная структура с элементами DDD (Domain-Driven Design).

## Технологии

- NestJS
- TypeScript
- TypeORM
- PostgreSQL
- npm

## Структура проекта

src/

## Установка

1. Склонируйте репозиторий:

   git clone https://github.com/elizabethkru/note-creator.git
   cd note-creator

2. Установите зависимости:

   npm install

## Настройка

Создайте в корне файл `.env` с переменными окружения (пример):

DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=ваш_пароль
DB_DATABASE=note_creator_db

Укажите свои параметры доступа к PostgreSQL.

## Запуск

- Режим разработки с автоперезагрузкой:

  npm run start:dev

- Сборка и запуск в production:

  npm run build
  npm run start:prod

## Основные эндпоинты API

- `POST /auth/login` – аутентификация, возвращает JWT-токен.
- `GET /users/search?useruuid=...` – поиск пользователя по UUID.
- `GET /tasks` – список всех заметок текущего пользователя.
- `GET /tasks/:id` – получить заметку по ID.
- `POST /tasks` – создать заметку.
- `PATCH /tasks/:id` – обновить заметку.
- `DELETE /tasks/:id` – удалить заметку.
- `GET /users` – список всех пользователей (только для администратора).

При запуске в режиме разработки доступна Swagger-документация по адресу `/api/docs`.
